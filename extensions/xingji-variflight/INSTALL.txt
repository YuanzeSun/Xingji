行迹 · 飞常准连接（电脑 Chrome / Edge）

1. 解压整个压缩包，保留这个文件夹。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”（Edge 可能显示“开发人员模式”）。
4. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的这个文件夹。
5. 回到 https://yuanzesun.github.io/Xingji/ 刷新网页，选择年份，再点击“查询历史行程”。

扩展没有后台程序或网页脚本，不包含、读取或保存 MCP Key。
唯一规则：为来自 yuanzesun.github.io、访问飞常准指定 MCP 接口的 POST/OPTIONS 响应补充会话读取声明及对应请求头预检声明。
每台电脑浏览器单独安装一次；更新扩展文件后，在扩展管理页点击重新加载。
