行迹 · 连接扩展（电脑 Chrome / Edge）

1. 解压下载的 ZIP 文件。
2. 打开 chrome://extensions 或 edge://extensions，启用「开发者模式」。
3. 如果装过单独的 12306 或飞常准连接扩展，先将旧扩展移除。
4. 点击「加载已解压的扩展程序」，选择解压后的 xingji-connector 文件夹。
5. 刷新行迹网页，再从「数据与同步」使用 12306 导入或飞常准历史行程。

使用 12306 时，打开官方积分查询页，用铁路 12306 App 扫码登录，保持该页面打开，再回行迹查询。
使用飞常准时，在行迹设置 MCP Key，按需查询历史行程、航班资料或航迹。
