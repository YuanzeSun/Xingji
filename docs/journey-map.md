# 行程地图

“行程地图”直接读取当前票库，支持切换图层、筛选年份、缩放和拖动。点击路线、铁轨或地点可以查看当前年份及图层中的相关票据。点击列表中的票据打开详情，关闭详情回到列表。航线图层将返程与去程归为同一条航线，同城机场独立显示。

火车使用12306参考表确定车站所属城市，再查城市参考点。同城的两座车站在「火车」图层只显示一个城市点。飞机用已识别的机场IATA代码查坐标。这两个视图用弧线连接不同的起终点，表示行程方向。无法确认坐标的票据暂不绘制。地图显示已存档票据，包括用户主动收藏的未来行程。

新增“铁路线”视图，复用每张火车票详情中的 RailGo 现行线路数据，只截取该票起终站之间完整匹配的区段，叠加真实铁轨走向。共用区段、返向区段及采样不同的重合直线段只绘制一次，平行但不重合的轨道保留。沿用年份筛选；显示匹配进度、未匹配和加载失败数量，加载失败可重试。无法匹配时留空，不回退到弧线或直线。线路按现行车次推定，不代表历史实测轨迹。

单票详情的线路图同时保存并显示列车全程：实际乘坐区间用金色实线，区间外使用同色、同亮度的虚线，车站保持清晰显示，初始视野包含全程。例如 G21 济南西→南京南会同时显示北京南→济南西及南京南之后的线路。全程数据不能用于总览地图的“已乘坐铁路线”叠加；总览仍只合并实际乘坐区间。

全部行程和年度行程都按出发时间顺序播放。每段随路线距离在 2 至 6 秒之间调整，短段也留出可看清轨迹的时间。「铁路线」图层只播放已匹配的铁路区段，按保存的轨迹长度计时。航线和地点弧线使用两端之间的距离。

地图在设备本地绘制。普通火车／飞机视图使用离线参考数据。「铁路线」与票据详情只读取各自票据保存的线路坐标，可离线叠加绘制。录入或编辑时主动查询 RailGo 可取得或刷新线路，随本张票据保存。地图模块在首次打开地图时加载，PWA 会缓存界面与本地参考数据。

## 数据来源

- 城市参考点：[GeoNames](https://www.geonames.org/)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。从CN与cities500快照中，仅保留应用所需城市的名称、坐标和GeoNames ID；同名行政区无法排除歧义时不自动取点。明确的行政区优先使用该区的行政驻地坐标。
- 机场坐标：[OurAirports](https://ourairports.com/data/)，Public Domain。只保留已有机场参考表中的IATA代码及WGS84坐标；重复代码对应不同坐标时不自动选择。
- 陆地轮廓、国家边界与省界：[Natural Earth 1:50m Land](https://www.naturalearthdata.com/downloads/50m-physical-vectors/50m-land/)、[1:50m Admin 0 Boundary Lines](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-boundary-lines/)、[1:10m Admin 1 Boundary Lines](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/)，Public Domain。筛选中国省级内部边界，保留全部原始顶点，并转换为与陆地相同投影的SVG路径，不主动抽稀轮廓。

`src/data/map-reference.js` 保存精简后的参考快照与来源、日期、原始文件SHA-256。完整原始数据库不随应用分发。运行 `pnpm update:map` 可重新下载并生成参考数据；普通构建不需要联网取地图数据。

地图数据与界面代码合计约2.5MB。网站托管可能采用gzip/Brotli进行无损传输压缩，浏览器接收后还原原文，不影响顶点数量或地图显示精度。
