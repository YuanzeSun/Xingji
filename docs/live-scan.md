# 票据录入与识别

在「录入」中选择交通方式后填写并保存。火车票的席别和无座状态分开记录。

## 火车票

在「二维码录入」中用相机扫描纸票二维码，也可以上传二维码图片。解码字段会填入并锁定。扫出完整行程后会查询一次 RailGo，匹配乘车日才会填入查询资料。

展开「扫描票面（alpha）」，可拍照或上传票面照片。拍照时让车票填满取景框再按快门。浏览器只读取拍下的画面，识别后填写表单，可打开原图核对。二维码录入成功后会锁住票面扫描，移除二维码后可恢复使用。

## 机票

在机票表单内实时扫描登机牌条码或电子登机牌二维码，也可以上传条码图片。解码字段自动填入并锁定。

扫码优先使用后置相机。可双指缩放或拖动滑条调整倍率，镜头随设备和浏览器能力自动切换。支持点按对焦的设备还可轻点画面，或用「对焦」按钮对准中央。 [扫码相机预览](images/camera-scan.jpg)

照片在本次编辑内用于校对，关闭编辑后释放。
