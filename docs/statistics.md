# 数据统计

统计直接读取当前票库中未删除的记录，不另建统计档案，也不再次按班次合并。重复导入同一张票仍由既有导入流程合并；不同旅客的有效票据分别保留。

退票费报销凭证单独存档，不计入乘坐次数、到访地点、行程时间轴或线路地图；它也不会和同班次的原车票合并。

OPEN 票、无效机票保留在票夹并在登机牌主券和副券上标识，不计入次数、机型、地点、国家／大洲、航线、折线图、地图或行程时间轴。改回正常机票后才按日期筛选口径统计。票夹的存档张数和搜索结果张数描述收藏内容，仍包含这两类票。

默认起始日期不限、截止日期为设备当地的今天。可自行选择起止日期或清空边界，范围包含起止日，只比较出发日期，不比较时刻。未来日期默认不计入，手动延后截止日期后可纳入。日期未知的记录不计入；仅记录年份或月份时，只有整个已知区间都落在筛选范围内才纳入，避免把模糊日期分配到未知的一侧。只有年份的票据计入年度图，不分配到具体月份。

乘坐次数折线图支持时间轴缩放、全览、手机双指捏合，以及电脑 Ctrl／Meta 加滚轮或触控板缩放；单指保留正常滚动。缩放围绕当前查看位置或手势中心进行，月份仍可横向滑动并跨年，切换页面保留缩放比例。按钮缩放采用平滑过渡，图表进入和切换年／月时有轻量动效；系统选择减少动态效果时停用动画。缩放只改变显示密度，不修改日期筛选范围或乘坐次数。

本次提供以下统计：

- 火车与飞机次数，以及按年、按月的折线图。无行程的年份和月份补零；月度图连续包含所有记录年份，可横向滚动跨年，也可用年份选择器跳转。年度图在年份较多时同样横向滚动。通过图上数据点查看次数，不再提供“查看图表数据”。
- 乘坐车型、担当路局，按已填写或经 RailGo 补全保存的字段统计；局名常见简称归并，车型代码统一大小写。可开启“细分车辆归属单位”，按路局及车辆归属单位分别统计；未收录单位的记录保留在所属路局的“单位未收录”组。它们不印在车票上，未填写时不猜测。

  车型支持普速客车与动车组。默认开启“细分子型号”，保留 CRH5G（技术提升型）、CR400BF-GS 等型号。票据只填写基础型号时，可从日期、车次、区间和型号均匹配的已保存车组资料补足子型。未填写车型时，可直接使用匹配的车组资料。关闭细分后，CRH5G 的各子型归入 CRH5G，已知的 CR400BF 技术配置归入 CR400BF 等对应系列。每次行程对同一统计分组计一次，车型字段和车组资料照常保存。

  子型号口径参考 [中车长客 CRH5G 技术提升项目](https://www.crrcgc.cc/ckgf/2016-10/28/article_B8CC21957935433BB01BC6ECFB7A05C6.html)、[中车四方 CR400AF-S 产品资料](https://www.crrcgc.cc/sfgf/2021-11/22/article_37881FC7258B4931A76E69A92BDB09EA.html)和 [RailGo 车型字典](https://github.com/RailGoApps/RailGo-Parser/blob/main/railgo/config.py)。
- 乘坐机型，按已有机型文字归并，统一大小写、厂商前缀和常见波音 B 前缀，不推断未填写的型号。默认“细分子型号”，关闭后将已识别型号归入系列，例如 737-200、737-800 和 737 MAX 8 合并为 737；DHC-8 的不同子型号合并为 DHC-8。模糊代码与未识别文字保持各自身份。
- 乘坐航司按航段计数，合并参考库已确认的航司代码、中英文名称和简称。默认按实际承运统计，已知为营销航司且承运方不明的航段计入未识别。切换到按购票航司时，优先使用已收录的营销航司，也可从票据上的航班号识别。
- 去过的大洲、国家、机场和火车站。按记录的起终点统计，不推断经停、实际入境或完整旅行足迹。无法确认身份的端点暂不计入。机场列表与按站名长度排列的火车站标签均限制高度并支持滚动；火车站只显示名称，电报码留在内部匹配和存储使用。
- 航线按具体机场配对，默认合并双向，可关闭“合并双向航线”分别统计 A→B 与 B→A。同一城市的不同机场分别统计；切换口径不改变乘坐次数等其他统计，也不修改票据。

铁路里程与实际飞行航程都按筛选日期汇总，并各自显示资料覆盖数。铁路使用票据上已收录的里程。飞机使用已保存的航迹，将各段内相邻坐标之间的距离相加。航迹的覆盖范围决定了可计算的距离，机场间的参考距离单独保存在票据上。

总在途时间按所选范围内的火车车次和飞机航段分别求和，同时显示各自的覆盖程数。火车使用已收录的出发和到达时刻。飞机优先采用完整的实际起降时间，缺少时用完整的计划时间。各端按票据时区计算，支持跨天和跨时区。只有能确定出发与到达时刻的行程参与求和。

## 地理归属

机场国家代码沿用 OurAirports 参考库，大洲来自同一数据源每个机场的 `continent` 字段，因此跨洲国家或海外机场不按国家名称粗略分配大洲。香港、澳门、台湾归入中国。国家名称使用浏览器的中文地区名称。

车站沿用 12306 参考表；该快照中的老挝站点万象、磨丁、纳堆、孟赛、琅勃拉邦、万荣归入老挝，其他站点归入中国。不会把未知的手写站名猜测成某个国家。

- [OurAirports 数据与许可](https://ourairports.com/data/)，Public Domain；[机场原始字段](https://github.com/davidmegginson/ourairports-data/blob/main/airports.csv)。`src/data/airport-geography.js` 保存按机场分组的大洲快照和原始文件 SHA-256，运行 `pnpm update:locations` 同步生成。
- [12306 公开查询](https://kyfw.12306.cn/otn/view/queryPublicIndex.html)列有老挝站点；[国家发展改革委关于中老铁路老挝段客运车站的说明](https://www.ndrc.gov.cn/fggz/lywzjw/202206/t20220629_1374240.html)。

统计在设备本地计算，不为统计发送票据或查询在线地理编码。

普速客车的供电制式也由“细分子型号”控制。开启时，“25G · DC600V”和“25G · AC380V”分别统计，缺少供电资料时显示“25G”。关闭后统一归入 25G。
