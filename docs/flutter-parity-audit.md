# Flutter 功能核查与 Apple 编译交接

核查日期：2026-11-18。Flutter 3.50.0 / Dart 3.14.0。现有网页版及 Pages 保留；Flutter Web 用于共用界面验收。

## 功能与接口

| 范围 | 本轮结果 |

## 明确尚未完成的部分

以下并非已实现的功能，不应在发布时宣称与网页版完全一致：

- 平台部分：Vision OCR／条码检测、拍照、系统分享及手机文件导出、Keychain 凭证保存。现阶段 GitHub 令牌仅在会话中使用；桌面文件保存和浏览器下载可用。
- 识别校准：共用层接受 OCR 行位置与原始条码字节，已有合并规则和测试；尚未用 Apple 的真实识别结果跑完用户提供的票样集。原生提供方接入后必须重新验收，不能用共用解析测试代替。
- 界面与导入差异：3D 球形票夹、网页版完整组合筛选／常用路线、PDF 原文件和 EML 邮件提取，以及纪念册的全部装饰与排版选项尚未迁入。当前搜索支持多关键词、地点别名及票面信息；邮件正文可粘贴导入。
- 新建空 GitHub 仓库还需先有初始提交和目标分支；当前连接流程不自动创建私人仓库或初始化空分支。
- 票面自定义标识及其位置调整、单票 SVG 导出入口仍需补齐；已保存的标识可随原票面渲染。

这些差异不阻碍先搭建 Mac 编译环境。原生扫描、分享与安全凭证保存须在正式手机版发布前完成；其余界面迁移按后续范围继续。

## 本轮验证

- 432 项浏览器测试通过，确认原有网页功能未被改动破坏。
- 52 项 Dart 共用层测试通过，覆盖 CSV 复杂字段往返、姓名证件预填、设置冲突、重置提交结构、OCR／条码合并、机型归类、匹配和不匹配的里程、车厢图链接过滤。
- Flutter 静态检查与 25 项测试通过，涵盖手机、平板、桌面及横屏布局、输入法、字段名与输入值不重叠、卧铺、批量删除、设置冲突后重新同步和重置。
- 构建 Flutter Web 和 Windows release；原生引擎测试使用实际 Windows QuickJS 动态库，继续比较原模板输出。
- 浏览器实操示例模式全选、CSV 下载、七张 PNG 打包 ZIP、个人资料保存与录入预填，检查无页面异常。导出的七张示例 CSV 可被原网页版读取，五张铁路线快照及两张登机牌条码均保留。
- 只读实测 RailGo 的 G21 主时刻表、里程接口及车厢链接返回结构；没有操作私人 GitHub 票库、执行实际重置、调用飞常准或验证 Apple 构建。

## 到 Mac 后的第一轮检查

本仓库设置的最低版本是 iOS 15.0、macOS 12.0，Bundle ID 为 `dev.yuanzesun.xingji`。优先使用相同 Flutter 版本和提交的锁文件；不要在第一轮同时升级依赖或重生成票面。

Xcode 与命令行工具准备参考 [Flutter iOS 设置](https://docs.flutter.dev/platform-integration/ios/setup) 和 [macOS 设置](https://docs.flutter.dev/platform-integration/macos/setup)。Flutter 3.50 使用 Swift Package Manager；首次在 Mac 构建会迁移生成相应接入，见 [官方 SwiftPM 说明](https://docs.flutter.dev/packages-and-plugins/swift-package-manager/for-app-developers)。当前 QuickJS、文件选择和偏好设置插件均含 Apple SwiftPM 包；QuickJS 的桥接代码由动态框架承载，必须检查 release 与归档后仍能正常渲染。

```sh
flutter --version
flutter doctor -v
cd packages/xingji_core
dart pub get
dart test
cd ../../apps/flutter
flutter pub get
flutter analyze
flutter test
flutter build macos --release
flutter build ios --simulator
flutter build ios --release --no-codesign
```

随后在 Xcode 选择自己的签名团队并测试真机。第一轮验收关注：七类票面和 CRH、关闭网络后的线路和线名、原生引擎在 release／归档中的加载、文件保存权限、触控板手势与 iPad 分屏。macOS 已声明联网及用户选中文件读写权限；相机和照片权限应在真正接入相应功能时加入用途文案。

平台通道数据约定见 [共用工程说明](flutter-development.md#平台能力接口)。Apple 构建、签名和真机能力仍需在 Mac 上实际验证。
